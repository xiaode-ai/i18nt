# 核心概念

i18nt 的设计理念是 **"极致轻量"** 与 **"开发者友好"**。

## 1. Proxy 驱动 (Proxy-Driven)

传统的 i18n 库通常使用字符串路径访问，例如 `t('auth.login.button')`。这种方式在大型项目中难以重构，且容易拼写错误。

i18nt 使用 **Recursive Proxy** 技术。当你访问 `t.auth.login` 时，Proxy 会动态捕获路径：
- **按需生成**：只有在访问时才会计算路径。
- **O(1) 初始化**：无论字典有多大，初始化时间都是恒定的。

## 2. ICU 标准化

我们不发明新的语法。i18nt 严格遵循 Unicode ICU MessageFormat 标准：
- **复数 (Plural)**：处理不同语言复杂的复数规则。
- **选择 (Select)**：根据性别、分类等选择不同文本。
- **格式化**：内置对日期、数字、列表的国际化格式化支持。

## 3. 跨语言一致性 (SSOT)

i18nt 认为 TypeScript 字典应该是项目的 **唯一事实来源**。通过 CLI，你可以将这些逻辑导出为 Python、Go 等语言的常量，确保前后端逻辑一致。
